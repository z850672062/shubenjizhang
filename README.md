# 书本记账

把每笔收支记进一本带标签的账本，说一句话就能完成记账 — 微信小程序。

<img src="assets/qr.jpg" alt="书本记账微信小程序码" width="220" />

微信扫码即可使用。

## 功能

- **AI 语音记账**：说一句「午饭 16.89」或「十七块八毛九」，自动识别金额、分类与标签，不用手动填表
- **标签记账**：每笔收支可以打多个标签，按标签归类回顾，看清钱花在了哪里
- **统计与多选筛选**：按时间、分类、标签多选筛选，查看分类占比与收支趋势
- **数据迁移**：支持从其他记账应用导入、导出数据，换应用不用从头再记
